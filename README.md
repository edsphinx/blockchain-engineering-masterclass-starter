# Blockchain Engineering Masterclass - Starter

**Welcome to the Engineering Lab.**

This is the starter repository for the **Blockchain Engineering Masterclass**. You will use this codebase as your persistent workspace throughout the entire series, evolving it from a simple TypeScript project into a complex distributed system.

## How to Use This Repo

### Option A: GitHub Classroom (Recommended)
If you are following the official course, use the **Assignment Link** provided in **Episode 01**. This will create a private repository for you (e.g., `blockchain-engineering-masterclass-student-name`) which will serve as your submission portal for **all future assignments**.

### Option B: Manual Setup
If you are self-studying, click the **"Use this template"** button at the top right of this page to create your own copy.

## The Mission

You are about to build:
1.  **A Monorepo Architecture** (pnpm + Turborepo)
2.  **A Cryptographically Secure Ledger** (SHA-256, Elliptic Curves)
3.  **A P2P Network** (WebSockets, Gossip Protocol)
4.  **Consensus Engines:**
    *   Proof of Work (PoW)
   ### Phase 2: High Performance (The Go Migration)
*   **Focus:** Concurrency, handling 10k+ connections, migrating to Proof-of-Stake, and **Deterministic Finality (BFT)**.
*   **Tech:** Go (Golang), Fiber, Goroutines, Tendermint Architecture.

### Phase 3: The System Level (Rust & WASM)
*   **Focus:** Memory safety, WebAssembly integration, and L2 Scaling (Rollups).
*   **Tech:** Rust, Arbitrum Stylus, Solana Architecture (PoH).

### Phase 4: The Frontier (Research & Beyond)
*   **Focus:** Zero-Knowledge Proofs, Avalanche Consensus, Hybrid Architectures, and Account Abstraction.
*   **Tech:** Circom, SnarkJS, Graph Structures, Snowball Algorithm.

## Requirements

- **Node.js:** v20 or higher
- **Package Manager:** pnpm (npm install -g pnpm)
- **Docker:** For running databases (LevelDB, Redis, Postgres)
